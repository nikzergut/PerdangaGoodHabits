# PerdangaGoodHabits

Main documentation: [../README.md](../README.md)

This folder contains the Tauri v2 desktop app and the shared frontend.

```bash
npm install

# Desktop
npm run tauri dev

# Web (same src/ folder, localStorage)
npm run dev:web

# Checks
npm run test:web
cd src-tauri && cargo test
```

See the root README for features, build instructions, and the live demo.
